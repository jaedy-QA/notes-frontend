# Notes Frontend Repository (`notes-frontend`)

React web interface for Notes App built with Tailwind CSS and Lucide React icons.

## Features

- User Authentication (Registration, Login, Logout)
- Clean, Minimalist Notes Dashboard
- Instant Search & Status Filtering (Active / Archived)
- Note Creation, Editing, Archiving, Restoring, and Deletion
- Strict validation feedback when attempting restricted actions (e.g., editing archived notes)

## Development

```bash
npm install
npm run dev
```
